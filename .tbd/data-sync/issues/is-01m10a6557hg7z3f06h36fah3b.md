A minimal or temporarily missing top-level kash initializer exposes a circular import: FileStore loads store_filenames, which initializes kash.model, whose compound action model imports kash.exec.combiners, which imports action execution and FileStore again. Move the Combiner type boundary into the model layer, add direct FileStore/public initializer regressions, and publish Kash 0.4.8 so downstream upgrades reinstall the canonical initializer.
